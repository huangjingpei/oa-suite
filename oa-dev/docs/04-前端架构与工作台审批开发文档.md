- **日期处理**：`Dayjs 1.11.11`（轻量级现代日期处理，内置 zh-cn 本地化）

## 3. 核心功能与交互中枢实现

### 3.1 协同工作台总控（Dashboard Workbench）
工作台采用“全局指标 + 多维事务标签页”的双层信息流架构：
1. **指标统揽卡片（Stat Cards）**：
   - **我的待办任务**：动态红点徽标展示待处理事务数量，引导即时批阅；
   - **已办审批归档**：历史处理量累计展示；
   - **我发起的申请**：实时跟进个人发起的公文/假勤/用印状态；
   - **考勤状态总览**：考勤打卡状态即时呈现与快速直达。
2. **待办任务列表（Pending Tasks）**：
   - 展示单据标题、申请人、所在部门、所处流转环节、任务类型（常规审批 / 加签转办）、到达时间；
   - 点击“办理审批”一键唤起 `ApprovalModal`。
3. **已办履历跟踪（Handled Tasks）**：
   - 包含实例状态标签（审批通过、已驳回、流转中、已作废）；
   - 点击“查看履历”打开流转历史时间轴弹窗。
4. **我发起的单据（My Submitted）**：
   - 全息呈现单据最新流转状态，支持在“审核中”阶段由发起人自主“撤回作废”。
5. **协同公文与公告（Announcements）**：
   - 汇总行政公文、重要通报与协同通知。

### 3.2 动态审批中枢与加签弹窗（ApprovalModal）
审批弹窗是工作流引擎的前端交互核心，完全匹配 M2 自研轻量状态机规范：
- **审批动作联动**：
  - `AGREE`（同意并流转）：提交审批意见并自动推向下一环节；
  - `ADD_SIGN`（加签委派）：动态唤起“加签处理人”下拉选择框（从 `oa_sys_user` 列表加载），指定加签对象并插入当前流转队列；
  - `REJECT`（驳回申请）：将当前流程直接驳回，终止流转并将实例置为驳回状态；
- **历史记录内嵌标签**：
  - 弹窗内集成 Tab 标签，审批人在处理过程中可无缝切换至“流转履历”，查看之前所有节点的审批批注、操作人与流转时间，免去来回跳转。

### 3.3 可视化审批履历时间轴（TimelineHistory）
- 基于 Ant Design Vue `<a-timeline>` 深度定制；
- 状态语义化配色：
  - 绿色点：审批同意（`AGREE`）
  - 红色点：驳回终止（`REJECT`）
  - 紫色点：前置/协同加签（`ADD_SIGN`）
  - 灰色点：作废撤销（`CANCEL`）
- 节点卡片化：展示环节名称、执行人姓名、工号、处理时刻与审批意见。

### 3.4 鉴权与安全路由守卫（Router Guard）
- 依据 Sa-Token 协议，前端将有效 Token 保存在 `localStorage`（键名 `satoken`）；
- 全局路由守卫自动检测路由 `meta.requiresAuth`：
  - 未登录用户重定向至 `/login?redirect=...`；
  - 已登录用户自动校验并填充 Pinia `userStore`；若本地凭据丢失或过期，自动触发注销逻辑并清空状态。

## 4. 接口调试与联调方案

在 `vite.config.ts` 中配置反向代理规则，解决跨域问题：
```typescript
server: {
  port: 3000,
  proxy: {
    '/api': {
      target: 'http://localhost:8080',
      changeOrigin: true
    }
  }
}
```
同时在 API 层内置 Mock 回退容错，当后端未启动时，能够平滑展示预置的演示数据与提示，确保界面随时具备良好的演示与自测体验。
