## 2. 五大业务领域前端实现规格

### 2.1 人事与考勤领域（HR）
1. **员工请假申请与假期台账 (`/business/leave`)**：
   - **交互表单 (`LeaveModal.vue`)**：
     - 支持事假、病假、年休假、调休、婚假、产假/陪产假、丧假等类型选择；
     - 集成 `a-range-picker` 时间区间联动，利用 Dayjs 毫秒级计算并自动推导请假工作小时数与折算天数；
     - 支持指定流转审批人与知会人，支持“暂存为草稿 (`isDraft = true`)”与“立即提交发起审批 (`isDraft = false`)”双操作。
   - **高保真纸质打印排版 (`LeavePrint.vue`)**：
     - 标准 A4 纸质双黑线网格公文签报表；
     - 包含单据流水号（`QJ2026...`）、员工信息、假期勾选框（`☑ 事假 ☐ 病假...`）、请假事由、主管审批意见栏、分管领导审批栏、人事部门审核归档栏；
     - 审批完成后自动在归档栏加盖带有日期的 SVG 矢量企业电子印章（`人力资源审批专用章`）。
2. **考勤打卡与漏卡补卡 (`/business/attendance`)**：
   - **功能集**：
     - **日常在线打卡**：支持模拟上班打卡（`ON`）与下班打卡（`OFF`），展示当前系统精确时间与打卡流水台账（工号、姓名、设备终端、IP 地址、迟到/早退/正常状态）；
     - **异常补卡申请 (`RepairModal.vue`)**：支持动态多行明细增删（漏卡日期、补卡班次、应修正打卡时间、事由及证明人）。
   - **高保真补卡打印排版 (`RepairPrint.vue`)**：
     - 结构化呈现多条漏卡明细子表格、主管意见栏与加盖考勤核准专用章。

### 2.2 行政公文与资产借阅领域（ADM）
3. **企业印章用印审批 (`/business/seal`)**：
   - **交互表单 (`SealModal.vue`)**：
     - 支持公章、合同专用章、法人名章、财务专用章、资质申报章等分类；
     - 联动展示：当选择“合同专用章”时，动态展示“关联合同金额（元）”与“相对方合作单位”必填校验项；
   - **高保真用印打印排版 (`SealPrint.vue`)**：
     - 企业印章使用审批签报表，包含部门意见、法务合规审核意见、总经理批准意见、印章管理员用印登记与盖印留样区，并在盖印区加盖企业鲜红公章印戳。
4. **红头公文拟稿发文与大厅 (`/business/redhead`)**：
   - **交互表单 (`RedheadModal.vue`)**：
     - 支持发文字号（如 `盛泰发〔2026〕18号`）、公文类型（通知/通报/决议/指令）、密级（普件/秘密/机密）、受众主送范围、正文多行内容、签发人；
   - **国家标准红头公文高保真排版 (`RedheadPrint.vue`)**：
     - 严格遵循党政机关与企事业单位公文排版规范（GB/T 9704-2012）：
       - 顶部鲜红大字发文单位头头（`盛泰智慧协同集团有限公司文件`）；
       - 鲜红公文分割双线（上粗 3px，下细 1px）；
       - 公文字号、密级标识（★ 机密）、签发人下划线；
       - 二号小标宋公文大标题、三号仿宋正文排版（首行缩进 2 字符）；
       - 发文机关落款与成文日期，加盖大红透底“发文专用章”电子公章（覆盖落款单位与日期）；
       - 底部版记：红单线、抄送单位、印发机构与印发份数。
5. **档案资料借阅台账 (`/business/borrow`)**：
   - **交互表单 (`BorrowModal.vue`)**：
     - 支持档案卷册名称、借阅形式（现场查阅/实体借出/复印摘录）、借出与应还时间区间；
   - **高保真打印排版 (`BorrowPrint.vue`)**：
     - 包含在库状态跟踪（未出库、借出流转中、已归还、已逾期）、档案管理员核验盖章栏与借阅安全保密守则。

## 3. 高保真打印引擎核心实现机制

### 3.1 A4 打印预览与原生打印隔离 (`PrintModal.vue`)
- **双模渲染架构**：
  - **屏幕预览态**：在网页端居中渲染 A4 仿真纸张（`210mm × 297mm`），带淡灰纸张背景与立体阴影，提供 `放大`、`缩小`（缩放比例 60% ~ 130%）与 `一键打印 / 另存为 PDF` 工具栏；
  - **物理打印态（`@media print`）**：
    ```css
    @media print {
      body * { visibility: hidden; }
      .no-print, .no-print * { display: none !important; }
      #print-paper-content, #print-paper-content * { visibility: visible; }
      #print-paper-content {
        position: absolute; left: 0; top: 0;
        width: 210mm !important; min-height: 297mm !important;
        margin: 0 !important; padding: 15mm 15mm !important;
        box-shadow: none !important; transform: none !important;
      }
      @page { size: A4 portrait; margin: 0; }
    }
    ```
  - 当调用浏览器的 `window.print()` 时，所有顶栏、侧边栏、弹窗底色与操作按钮自动隐藏，打印机输出完美无缝的纯净矢量公文！

### 3.2 动态 SVG 电子防伪印章 (`ElectronicStamp.vue`)
- 解决传统位图印章分辨率低、放大失真、背景不透明遮挡文字的痛点；
- 采用原生 SVG 矢量绘制：
  - 外圈双红环（外粗 4px、内细 1.5px）；
  - 顶部环形文字路径 `<textPath>`，使企业全称自适应沿圆周排布；
  - 核心五角星徽记（`<polygon>` 坐标拟真）；
  - 横向印章类型与审批日期；
  - 8 度微倾斜角度与 85% 半透明度，仿真盖印渗透纹理。
