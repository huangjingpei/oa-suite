## 1. 移动端 H5 专版架构设计（方案 A）

为兼顾研发效率、部署维护简易度与单一代码库资产沉淀，移动端采用**响应式轻量专版路由体系（`/m/...`）**，在同一前端工程（`oa-frontend`）内无缝实现移动端与 PC 端的协同闭环：

```
                              ┌──────────────────────────────────────────────┐
                              │            现代化协同办公前端入口            │
                              ├──────────────────────┬───────────────────────┤
                              │ PC 电脑端完整总控台  │ 移动端 H5 专版触控视图│
                              │ 路径: /dashboard     │ 路径: /m/...          │
                              └──────────┬───────────┴───────────┬───────────┘
                                         │                       │
                    ┌────────────────────┴───────────────────────┴────────────────────┐
                    │                                                                │
     ┌──────────────▼─────────────┐                                   ┌──────────────▼─────────────┐
     │      PC 骨架 (BasicLayout) │                                   │    移动骨架 (MobileLayout) │
     ├────────────────────────────┤                                   ├────────────────────────────┤
     │ 1. 侧边栏伸缩与多级树形导航│                                   │ 1. 顶部紧凑标题与回退键    │
     │ 2. A4 纸质高保真打印预览   │                                   │ 2. 底部悬浮 TabBar 导航    │
     │ 3. 组织/用户/字典管理大厅  │                                   │ 3. 巨型呼吸打卡动效        │
     │ 4. 复杂业务台账与多维统计  │                                   │ 4. 底部弹出式审批决策抽屉  │
     └────────────────────────────┘                                   └────────────────────────────┘
```

## 2. 移动端核心功能实现规格

### 2.1 移动端布局骨架 (`MobileLayout.vue`)
- **自适应视口容器**：在手机端以 100% 视口全屏沉浸呈现；在电脑端屏幕居中呈现仿真手机容器（`max-width: 480px`），并带有立体微阴影，方便开发调试；
- **顶部导航**：动态标题感知、智能回退键控制（非 Tab 主页时自动展现返回箭头）；
- **底部 TabBar**：工作台、打卡考勤、待办审批（红点徽标实时提示待办数）、我的信息。

### 2.2 移动端协同工作台 (`/m/dashboard`)
- **员工身份卡**：彩色渐变卡片呈现员工姓名、部门及岗位身份；
- **九宫格快捷入口**：快速发起请假、快速用印申请、移动在线打卡、待办事务；
- **待处理卡片流**：直观展示待办标题、发起人、所属流程与到达时间，轻触卡片即可直接唤起底部抽屉审批决策面板。

### 2.3 移动端定位考勤打卡 (`/m/clock`)
- **定位与 WiFi 围栏仿真**：直观反馈“已进入办公园区 WiFi 打卡有效范围”；
- **数字时钟**：毫秒级实时时钟；
- **巨型动态打卡按钮**：圆环呼吸动效，根据今日打卡状态自适应切换“上班签到（蓝青渐变）”与“下班签退（翠绿渐变）”；
- **今日足迹时间轴**：按时序罗列今日打卡具体时刻、终端及签到位置。

### 2.4 移动待办审批中枢 (`/m/todo`)
- **分段控制器（Segmented）**：一键切换“我的待办事务”与“我已处理审批”；
- **底部抽屉审批流转**：点击卡片滑出底部轻量抽屉，单手即可完成“同意推进”、“加签转办”、“驳回终止”并提交批注意见。

### 2.5 移动端极简发起表单
- **请假申请 (`/m/apply/leave`)**：假种选择、触控日期时间选择器、天数/小时自动换算、事由填报；
- **用印申请 (`/m/apply/seal`)**：印章类别、文件名、份数、事由填报，提交后即时启动流转。

## 3. 全套 Docker 容器化一键部署规范

工程在 `E:\OA\oa-suite\oa-dev/docker/` 目录下提供了完整的生产级容器化编排资产：

```
docker/
├── docker-compose.yml           # MySQL 8 + Spring Boot 3 + Nginx 容器编排总控
├── nginx.conf                   # 生产级 Nginx 配置 (Gzip/缓存/代理/50M上传)
├── start.bat                    # Windows 平台一键拉起容器脚本
├── start.sh                     # Linux / macOS 平台一键拉起脚本
├── stop.bat                     # Windows 平台安全停止脚本
└── stop.sh                      # Linux / macOS 平台安全停止脚本
```

### 3.1 容器编排架构 (`docker-compose.yml`)
1. **`oa-mysql` (MySQL 8.0)**：
   - 字符集与排序规则：`utf8mb4_0900_ai_ci`；
   - 自动挂载 `../sql/schema.sql` 与 `../sql/seed-data.sql` 到 `/docker-entrypoint-initdb.d/`，**新部署容器首次拉起时全自动完成 18 张核心业务表与种子数据的建表初始化**；
   - 健康检查探针：`mysqladmin ping` 保证依赖健康启动。
2. **`oa-backend` (Spring Boot 3)**：
   - 基于 `eclipse-temurin:17-jre-jammy`；
   - 针对容器化运行环境进行 JVM 调优参数注入：`-Xms256m -Xmx512m -XX:+UseG1GC -XX:MaxGCPauseMillis=200`；
   - 自动等待 MySQL 数据库健康后拉起服务。
3. **`oa-frontend` (Nginx Alpine 网关)**：
   - 托管打包生成的生产静态资产（`oa-frontend/dist`）；
   - 反向代理 `/api/` 路由到后端集群，并具备健康检查探针 `/healthz`。

### 3.2 生产级 Nginx 调优配置 (`nginx.conf`)
- **Gzip 压缩**：压缩级别 6，覆盖 json、css、js、xml；
- **静态资源强缓存**：针对静态 assets 设置 `Cache-Control: 30d, immutable`；
- **大文件上传**：`client_max_body_size 50m;` 确保公文盖章扫描件与附件上传顺畅；
- **单页面路由支持**：`try_files $uri $uri/ /index.html;` 完美兼容 Vue Router HTML5 History 模式。
